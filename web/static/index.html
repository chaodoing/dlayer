🔌 数据库连接与测试

配置目标数据库驱动及连接字符串 (DSN)，并实时获取数据表列表

数据库配置

支持 MySQL, TiDB, PostgreSQL, SQLite, SQL Server, ClickHouse, 达梦, Oracle, GaussDB
示例: root:password@tcp(127.0.0.1:3306)/dbname?charset=utf8mb4&parseTime=True&loc=Local

常用驱动 DSN 模版参考

生成路径与包名设置

配置代码生成的输出目录及 Validator 包名称
未显式指定子路径时，其余输出目录将基于此根目录扩展
选择验证器中间件对应的 Web 框架类型
从表名中剥离公共前缀，例如 tb_users 将生成 User 模型和 UserRequest 验证结构体

验证器与 Tag 配置

控制请求结构体生成的 Tag 名称、忽略字段与验证场景
生成结构体字段上的 Tag 属性，例如 `json:"name" form:"name" xml:"name"`
生成验证结构体时忽略的数据库列，默认自动忽略 created_at, updated_at, deleted_at

数据库表过滤 & 选择

留空或选择全部时，默认生成当前数据库所有表
💡 尚未获取数据库表列表，请先在“数据库连接”页面测试连接。

全局数据库类型映射 (Type Mappings)

支持将数据库中的字段类型全局映射为特定的 Go 类型（如 uuid.UUID, datatypes.JSON）
快速模版:
数据库类型 (DBType) Go 类型 (GoType) Import 路径 (ImportPath) 操作

单表独立字段类型配置 (Table Field Overrides)

针对特定表中的列独立配置 Go 类型和 Import 路径，ORM 模型和验证器结构将同步生成
💡 请在右上角下拉列表中选择需要单独配置字段类型的数据库表。
